# Specification: The Grada Brand Transition

## 1. Overview
Transition the `deploy-stack` codebase to the new brand identity: **Grada**. 
Existing deployments must not break; implement robust dual-read fallbacks for state files, machine markers, and tags. Version bump to `0.32.0`.

## 2. NPM, Repository & Binary Renaming
- `package.json`: Update name to `grada-run`. Update `author` and `keywords` to include Grada terminology. 
- `package.json`: Map the `bin` field to: `"grada": "./bin/cli.js"`, `"grada-run": "./bin/cli.js"`, and a deprecated fallback `"deploy-stack": "./bin/cli.js"`.
- `package.json` fields (`repository`, `bugs`, `homepage`) must point to `[https://github.com/grada-run/grada](https://github.com/grada-run/grada)`.
- Replace hardcoded `anton-codes-iac/deploy-stack` GitHub URLs across the codebase (error logs, docs) with `grada-run/grada`.
- Rename `CLI_ENTRY_BASENAMES` in `src/core/telemetry.js` to include `grada` and `grada-run`.
- Update CLI banner texts, `.muserules` title, AI rules filenames (write new ones, do not delete user legacy ones), and help texts to use `Grada` / `npx grada-run`.

## 3. Dual-Read Local State & Env Vars
Read from `.grada/` first, fall back to `.deploy-stack/`. Write new state to `.grada/`.
- **Telemetry:** Check `~/.grada/telemetry-id` (raw text file) -> fallback to `~/.deploy-stack/telemetry-id`. Copy to new path on fallback.
- **Sleep Ledger:** Check `.grada/sleep-state.json` -> fallback to `.deploy-stack/sleep-state.json`. In `ensureSleepGitignore`, append `.grada/` but leave `.deploy-stack/`.
- **Bedrock Cache:** Check `~/.grada/bedrock-models-cache.json` -> fallback `~/.deploy-stack/bedrock-models-cache.json`.
- **Env Vars:** Rename `DEPLOY_STACK_TELEMETRY_ID_PATH` -> `GRADA_TELEMETRY_ID_PATH`, `DEPLOY_STACK_FRAMEWORK` -> `GRADA_FRAMEWORK`, and `DEPLOY_STACK_BEDROCK_CACHE_PATH` -> `GRADA_BEDROCK_CACHE_PATH` (all with legacy read fallbacks). Leave `DO_NOT_TRACK` as the sole telemetry opt-out. Rename `DEPLOY_STACK_BYPASS` in the Svelte template to `GRADA_BYPASS`.

## 4. Machine Markers (Dual-Read)
The CLI must parse both `deploy-stack` and `grada` variants for existing files, but write `grada` for new ones.
- Domain mode: `# deploy-stack:domain-mode=` / `# grada:domain-mode=` AND `# deploy-stack:zone-id=` / `# grada:zone-id=`
- Migrate gate: `# deploy-stack:db-migrate-start` / `# grada:db-migrate-start` AND `# deploy-stack:db-migrate-end` / `# grada:db-migrate-end`
- AI Context: Dual read both HTML (`<!-- BEGIN GRADA CONTEXT -->` / `<!-- END GRADA CONTEXT -->`) and hash (`# BEGIN GRADA CONTEXT` / `# END GRADA CONTEXT`) block variants.

## 5. Templates, Tagging & Eject
- Rename *all* cosmetic occurrences of the brand in templates (e.g., `npx deploy-stack` -> `npx grada-run`, `Generated by deploy-stack`, `# deploy-stack generated infrastructure`, `# deploy-stack addon:`, `deploy-stack-cron`, and git commit messages).
- Update `ManagedBy = "grada"` for new writes in templates, S3 state buckets, RDS snapshots, and providers. Rename `startedBy` to `grada-db-*`.
- In `src/commands/eject.js`, ensure the cleanup regex strips *both variants* of all four block types: `ManagedBy` tag blocks, cosmetic addon headers, `# deploy-stack backups` gitignore comments, and `# deploy-stack generated infrastructure` main.tf headers.

## 6. Documentation & Generators
- **Docs Site (`apps/docs/`):** Update `astro.config.mjs` (`site: '[https://grada.run](https://grada.run)'`, remove the `base` property entirely, update `title`, `editLink`, `social` hrefs, redirects, and sidebar labels). Execute Astro build to regenerate `apps/docs/dist/`. Update internal `/deploy-stack/` links across `README.md`, `release_notes.md`, and all `apps/docs/src/` pages.
- **Generator Fallback Doc:** Rename fallback constant to `GRADA.md`. `resolveDocDest` precedence chain: `README.md` -> `DEPLOYMENT.md` -> `GRADA.md` -> legacy `DEPLOY-STACK.md` (returning the first missing-or-managed). 
- **Cost Sync:** `syncDocCostEstimate` must scan `GRADA.md` and legacy `DEPLOY-STACK.md` in addition to `README.md` and `DEPLOYMENT.md`.

## 7. GitHub Actions & CI
- Update `uses:` step from `anton-codes-iac/deploy-stack-action@v1` to `grada-run/grada-action@v1`.
- Update `scripts/test-iac.js` and `iac-validation.yml` to assert the new `grada` migrate markers.
- Validate that `.github/workflows/publish.yml` publishes `grada-run` and the scoped alias `@grada-run/grada`.

## 8. Testing
- Use `npm run test:update` to carefully update the 131 legacy snapshot matches across the 12 test files.
- Add unit tests asserting the dual-read marker logic, telemetry fallback, sleep ledger fallback, and `eject` multi-brand cleanup.
